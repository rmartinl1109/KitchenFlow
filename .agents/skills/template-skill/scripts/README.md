# Scripts de Apoyo para el Skill

Coloca en este directorio los scripts ejecutables (PowerShell `.ps1`, Python `.py`, SQL `.sql`, Bash `.sh`, etc.) que el agente o el usuario puedan ejecutar para automatizar pasos del skill.

En el archivo `SKILL.md`, enlázalos usando rutas relativas, por ejemplo:
`[ejecutar-tarea.ps1](./scripts/ejecutar-tarea.ps1)`
